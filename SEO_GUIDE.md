## 📊 Métriques à surveiller

### Core Web Vitals
- LCP (Largest Contentful Paint) < 2.5s
- FID (First Input Delay) < 100ms
- CLS (Cumulative Layout Shift) < 0.1

### SEO Technique
- Vitesse de chargement
- Taux de rebond
- Temps de session
- Pages par session
